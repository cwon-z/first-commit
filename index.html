Why this course clicks when others don't

⌨️

A terminal you can't break

Practice in a fully simulated sandbox that behaves exactly like real git — same commands, same output, same error messages — with zero risk to your computer. Merge conflicts, detached HEAD, rejected pushes: meet them all safely.

🌳

See your history, live

Branches and commits are invisible in real git — that's why they're confusing. Here, a commit graph redraws itself after every command you run, so the mental model builds itself while you type.

🎯

Real understanding, verified

Challenges check the actual state of your repository — not the commands you typed. Solve it your own way; if the history is right, you pass. Guided steps, progressive hints, and instant feedback keep you moving.
